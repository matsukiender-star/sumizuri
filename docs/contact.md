# Contact

Pick whichever is easiest for you.

## Discord

For questions, help and chat, join the [Sumizuri Discord](https://discord.gg/JZaqv5VFj7).

## Report a problem

To report a bug or ask for a feature, open an issue on [GitHub](https://github.com/not-akari/sumizuri/issues). Say which device and which version of Sumizuri you use, and what you did before it went wrong.

## Rights holders

Sumizuri holds no content, so there is nothing in the app or on this website to take down. To have content removed, contact the site that hosts it. See the [terms](/terms).
