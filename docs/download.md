# Download Sumizuri

Pick the file for your device. Sumizuri comes with no content, and you bring your own.

<DownloadList />

## Which Android file?

If you are not sure, take **Universal**. It works on every phone. The others are smaller and only fit one kind of processor. Most phones from the last years are **ARM 64-bit**.

## Install

The Mac disk image and the iPhone and iPad file are not signed, so they need a few extra steps. See the [install steps](https://github.com/not-akari/sumizuri#install) on GitHub for every device, and for how to update.

## Sync server

The sync server comes as a Docker image, and each release has the files to run it. They are listed above under Sync server. See [Run your own sync server](/sync-server) for the steps.
